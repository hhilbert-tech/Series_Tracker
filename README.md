# Series Release Tracker

Offline-first phone app (installable PWA) that follows the book series and authors you read and tells you when a new book is announced, dated or released. Data comes from Hardcover; everything is stored on your phone.

See [`phone/README.md`](phone/README.md) for setup, features and development. Pushes to `main` that touch `phone/` are tested and published to GitHub Pages by `.github/workflows/pages.yml`.

The earlier Python/FastAPI server version was retired; it remains in git history (commit `f796a60` and earlier).
