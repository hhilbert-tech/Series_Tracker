# Handoff — Book Finder (phone PWA, formerly Series Tracker)

**Repo:** `hhilbert-tech/Series_Tracker`, branch `main`. App lives in `phone/`; every push touching it runs `npm test` and deploys to GitHub Pages (`.github/workflows/pages.yml`). Python version was retired (in git history ≤ `f796a60`).

**Stack:** vanilla ES modules, no build. IndexedDB store (`store-idb.js`, `MemStore` twin for tests), hash router in `js/app.js`, service worker `sw.js` (stale-while-revalidate; bump `CACHE` name and add any new js file to `SHELL` on every release). Visible version string lives in `viewMore()` (currently "v20"). Tests: `cd phone && npm test` (node:test, 100 passing).

**Key files:** `app.js` (all views + actions), `hardcover.js` (all GraphQL), `check.js` (release detection), `db.js` (progress model), `authors.js`, `recs.js` (suggestions), `format.js` (dates, store links), `ics.js` (calendar export), `covers.js`.

**Progress model:** `user_progress.max_position_read` + per-book overrides `series_book.read` (true/false) via `isRead(row, max)`; `read_at` stamped when marked read; `series.last_read_at` for sorting.

**Layout (v17):** tabs Discover · Want to read · Search · More. Discover (`#/`, `viewDiscover`) = search box, filters, book-finder shelves; pick page `#/pick/<key>` (query string carries the book so links survive cache changes); series-only picks use `#/rec/<id>`; `#/like` = Books like…. Want to read (`#/want`, `viewWant`) = saved picks. Following lives under More (first entry, links to `#/following`; `MORE_BACK` back link) with a sub-nav (`followNav`): Series & authors (`#/following`) · Releases (`#/releases`) · Updates (`#/updates`); the unread badge sits on the More tab and on that entry. IndexedDB name, backup `app` id and `st-theme` key unchanged on purpose.

**Finder (`recs.js`, v2 cache):** book-level picks keyed `s:<seriesId>` (one per series) or `b:<bookId>` (standalones). Tiers: similar books (seeds = favourites first at 2× weight, then most recent reads: series_book, imported `book` rows, author_book.read) → followed-author books (local, `authorPicks`, computed at display time) → subgenre tags → other series by authors of followed series → genres. Series picks not at #1 are swapped to book #1 via `client.firstBooks` (one request; `via` keeps the matched book) unless #1 is read. Cached 7 days in setting `recs` (`v: 2`; old numeric dismissals map to `s:<id>`); builds run via `startRecsBuild()` in app.js (one at a time; never-built or invalidated caches rebuild on the next Discover visit, stale ones at most every 6 h; low-stock refill at most hourly); `buildRecs` saves a `partial` list after the similar/author steps. Settings: `favourites` [{id,title}], `want` (saved items, `hc_user_book_id` when Hardcover accepted it), `recs_dismissed`, `recs_dislikes` {authors, groups} (≥2 sinks), `recs_hidden_authors`, `pick_filter`. `similarTo()` powers "Books like…" (`#/like`) and the shelf on book pages. Hardcover requests time out after 25 s.

**Alerts (v18):** series (`check.js`), followed authors (`authors.js`) and single watched books (`watch.js`, setting `watch`, 🔔 buttons; `runWatchCheck` runs inside `runCheck` with one `booksInfo` call; kinds `dated` / `date_changed` / `released`, the last only for a book seen with a future date; log rows carry `watch: 1`). Want-to-read saves of unreleased books auto-watch (`auto: true`, dropped again on remove). `followSeries` takes `info.mode` ('new' = progress to last released) and always raises progress from books already in your history (`readBooks`). Follow buttons are `followMenu()` (details menu with both modes).
